# Structural attempt on φ(ℤ/4) = 4: reduction to a sumset statement

Status, 26 November 2026: **not proved.** The attempt turns the problem into a statement about sums of multisets over ℤ/4. Three results are proved, and each is conditional on published or computer-checked inputs:

- Theorem 1: a general reduction.
- Theorem 2: φ(ℤ/4, 5) = 4 follows from an explicit sumset criterion.
- Proposition 3: the sumsets involved are lattice-convex.

The sumset criterion is verified by computer for every degree up to 6. Proving it for every degree is the remaining step for five leaves. The induction to six or more leaves has the same shape and is only tested so far.

Notation:
- G = ℤ/4. A *margin* on n leaves is a tuple (C_1, …, C_n) of multisets of size d over G.
- The *fibre* is the set of tables (multisets of d zero-sum rows) with those column multisets.
- For a set of leaves A, μ_A(T) is the multiset of row sums over A.
- A *cherry* is a 2-element set of leaves.
- For multisets α, β of the same size, the *sumset* α ⊕ β is the set of all multisets {a_i + b_{π(i)}} as π ranges over bijections. This is the set of row-sum multisets of all ways to pair α with β.

## Theorem 1 (reduction by toric fibre products)

Let n ≥ 5 and suppose φ(G, k) ≤ 4 for 3 ≤ k < n. Consider the graph on each n-leaf fibre that joins two tables when they have equal μ_A for some split A | A^c with |A|, |A^c| ≥ 2. If that graph is connected for every n-leaf margin, then φ(G, n) ≤ 4.

*Proof.*
1. Two tables with μ_A(T) = μ_A(T′) give a binomial in the toric ideal of the tree with two inner vertices obtained by splitting the claw along A. That ideal lives in the same variables, because every claw flow is a flow on that tree, with interior edge label Σ_A g.
2. The tree is a codimension-zero toric fibre product of K_{1,|A|+1} and K_{1,|A^c|+1}. By Sullivant's theorem (Toric fiber products, J. Algebra 2007, arXiv math/0602052) its ideal is generated in degree ≤ max(2, φ(|A|+1), φ(|A^c|+1)) ≤ 4.
3. A connected graph therefore gives a chain of degree-≤4 moves between any two tables of the fibre. By Charalambous–Katsabekis–Thoma this means the ideal is generated in degree ≤ 4. ∎

This is an ideal-theoretic form of Donten-Bury–Michałek's Conjecture 3.6 (sum of the ideals of the prolongations). Their paper states only the scheme-theoretic version and sketches the implication.

## Theorem 2 (five leaves reduce to sumsets)

For a 5-leaf margin, form the graph Γ as follows.
- Nodes are pairs (cherry {i,j}, α) with α ∈ C_i ⊕ C_j.
- (ij, α) and (kl, β) are joined whenever the cherries are disjoint, the fifth leaf is m, and −C_m ∈ α ⊕ β.

**If Γ, restricted to nodes with at least one edge, is connected for every 5-leaf margin of every degree, then φ(ℤ/4, 5) = 4.**

*Proof.*
1. Joint attainability: some table has μ_{ij} = α and μ_{kl} = β if and only if α ∈ C_i ⊕ C_j, β ∈ C_k ⊕ C_l and −C_m ∈ α ⊕ β.
   - For the "if" direction, pair C_i with C_j to realise α, pair C_k with C_l to realise β, and pair α with β so that the sums are −C_m. Each glued row (x_i, x_j, x_k, x_l, −s−t) is then a flow.
   - The "only if" direction is immediate.
2. Every table T carries a node for each cherry, and those nodes are pairwise joined in Γ. Two tables sharing a node are connected by Theorem 1, using φ(3) = φ(4) = 4.
3. A path in Γ therefore gives a chain of tables, each consecutive pair sharing a node.
4. Every attainable node has an edge, because a table attaining it also has a value at a disjoint cherry. ∎

The criterion involves no tables, only sumsets of four-entry count vectors.

## Proposition 3 (sumsets are lattice-convex)

For all multisets α, β of size d over ℤ/4, α ⊕ β is exactly the set of lattice points of its convex hull. Here the lattice is {z : Σ z_s = d, Σ s·z_s ≡ Σ s·α_s + Σ s·β_s (mod 4)}.

*Proof.*
1. The margin (α, β, −z) is feasible for the tripod if and only if z ∈ α ⊕ β.
2. Dinu–Vodička (arXiv 2309.05301, Thm 5.1) prove that the ℤ/4 tripod polytope is normal. So the margin semigroup equals its cone intersected with the lattice generated by the vertices.
3. That lattice is cut out by equal block sums and the weighted congruence above (Donten-Bury–Michałek).
4. Slicing the cone at fixed (α, β) gives a polytope in z, and its lattice points are exactly α ⊕ β. ∎

Checked directly by linear programming for every pair with d ≤ 6. Empirically, the hulls have only **18 facet directions**, the same set for every d from 4 to 8: lower bounds on each z_s, the odd count z_1+z_3, z_3−z_1, Σ|s−t|·z_s, and Σ((±s+t) mod 4)·z_s. The same normality argument applied to the 4-leaf claw (checked normal by Dinu–Vodička) makes three-fold sumsets lattice-convex as well. So every set in Theorem 2 is the set of lattice points of an explicit polytope. That is the setting of Rauh–Sullivant's lifting theory (J. Symb. Comput. 2016, arXiv 1404.6392, Thm 16 and Lemma 18), with φ = μ_{12} and B_φ = the glued tree.

These agree with the brute-force fibre search, which found no disconnected fibre at 5 leaves for d ≤ 6.

## What remains

1. **Five leaves, all degrees.** Prove that Γ is connected for every d. The data suggest a sharper statement: for a middle leaf m whose column is not too degenerate, the bipartite graph between α ∈ C_i ⊕ C_j and β ∈ C_k ⊕ C_l (edge when −C_m ∈ α ⊕ β) is connected. Collapsing the A-leaves and B-leaves to single columns, this says the lattice points of the polytope {(α, β) : (α, C_m, β) is a feasible tripod margin}, intersected with lattice-convex sets, can be joined by changing α or β one at a time ("rook-connected"). Everything is polyhedral with a fixed facet family. One route is a hand proof via the 18 facets. Another is a parametric or Presburger argument, since the statement is linear in the margin.
2. **Six or more leaves.** Merging two middle leaves maps an n-leaf margin to (n−1)-leaf margins, one for each D ∈ C_a ⊕ C_b. Induction then reduces connectivity to linking these slices, which is again a sumset-attainability statement. Tested only at six leaves (d ≤ 5).
3. **Inputs to recheck before any claim.** φ(3) = φ(4) = 4 (Sturmfels–Sullivant tables, reproduced with 4ti2). Normality of the tripod and of the 4-leaf claw (Dinu–Vodička). Sullivant's toric fibre product theorem.
