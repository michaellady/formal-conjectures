# Recent work (2018–2026) and applicable methods for (a) Z/4 degree ≤ 4 on all claw trees and (b) constancy of φ(G, n)

Sweep run 22–23 Nov 2026. Conventions: φ(G, n) = φ(G, K_{1,n}) with n = number of leaves (Michałek–Ventura convention). Sturmfels–Sullivant's 2005 table uses n = number of leaves minus one (their row "Z2, n = 2" has 0 generators, which is K_{1,3}); I translate to the leaf convention below. ## Key question 1 — Citation sweep (OpenAlex `filter=cites:<id>,from_publication_date:2018-01-01`; Crossref)

### Takeaway
No work citing any of the seed papers since 2018 proves anything about generators of the ideal for Z/4 or any cyclic group of order ≥ 4 on claw trees, computes a new value φ(G, n), or addresses constancy in n (Conj. 9.3 / 4.3); the only post-2017 theorem on phylogenetic complexity in the citation graph is Michałek–Ventura's φ(Z2×Z2) = 4 (Adv. Math. 2019). The one new 2026 item that touches Z/4 on a claw tree (Marín Muñoz, arXiv:2609.02630) only shows the Z/4 tripod ideal is not a complete intersection.

### Inferences
- Problem (a) is open and untouched since 2017: known values are φ(Z4, 3) = φ(Z4, 4) = 4 by 4ti2 (2005, reproduced here); nothing is published for n ≥ 5, and φ(Z4) is known to be finite only non-effectively (M–V 2017).
- φ(G, ·) is non-decreasing in n (my argument, not found stated as a lemma in the papers read): flows on K_{1,n+1} with last entry 0 are the vertices of a face of P_{G,n+1} (maximise the coordinate "leaf n+1 carries 0"), the face is a copy of P_{G,n}, every fibre of the face is a full fibre of the big configuration, so a minimal generator of degree d for K_{1,n} stays a minimal generator for K_{1,n+1}. Pochuev's note uses the same "appending zero columns" step. Hence Conj. 9.3 is equivalent to φ(G, n + 1) ≤ φ(G, n) for n ≥ 3 (n ≥ 4 for Z2).
- With that monotonicity, constancy is already a theorem for G = Z2 (S–S Thm 26, from n = 4), Z3 (φ(Z3, 3) = 3 = φ(Z3)) and Z2×Z2 (φ(·, 3) = 4 = φ). For G = Z4, problems (a) and (b) coincide: since φ(Z4, 3) = 4, "(b) for Z4" ⇔ "φ(Z4, n) = 4 for all n" ⇔ (a). Z4 is therefore the smallest group for which the constancy conjecture is open.
- The M–V 2019 proof template (small n by machine, a regularity-assisted middle case, large n by table combinatorics) is the only existing blueprint for (a); it needed a 1 TB machine at 256 variables, which is exactly the size of Z4 at n = 5.

**The Pochuev counterexample (read: OpenAlex abstract + GitHub README + data file; the 5-page PDF itself was not opened):**
- Claim: for G = Z/17Z, two compatible 18×3 tables of zero-sum rows whose common column multisets admit exactly two zero-sum tables up to row permutation, with disjoint row supports; hence φ(Z/17, 3) ≥ 18 > 17, disproving φ(G) ≤ |G| ([SS05] Conj. 29 / M–V Conj. 4.1) and also M–V Conj. 4.2 (φ(G, 3) ≤ |G|); "by appending zero columns, φ(Z/17, n) ≥ 18 for every n ≥ 3" — [GitHub README](https://github.com/Grisha-Pochuev/phylogenetic-complexity-z17-counterexample)
- Status per the author: "working manuscript for independent mathematical verification"; "External expert review, publication priority, and publication status are not asserted here"; "The manuscript and verification package were prepared with AI assistance." OpenAlex lists the landing page as a Zenodo record — [GitHub README](https://github.com/Grisha-Pochuev/phylogenetic-complexity-z17-counterexample); [OpenAlex record W7211966735](https://api.openalex.org/works/W7211966735)
- Stated checkable invariants: 22 possible row types within the three column supports; incidence matrix rank 21, nullity 1; fibre = {A, B}; 96 labelled fillings (24 + 72) — [GitHub README](https://github.com/Grisha-Pochuev/phylogenetic-complexity-z17-counterexample)
- Own check: I downloaded `data/tables_Z17.json` and, with my own script (not the author's), confirmed: all 36 rows sum to 0 mod 17; column multisets of A and B agree; A and B share no row; exactly 22 zero-sum row types lie in the column supports; exhaustive enumeration of nonnegative solutions gives exactly 2 tables in the fibre, namely A and B. A two-element fibre with disjoint supports is an indispensable binomial of degree 18, so the claim φ(Z/17, K_{1,3}) ≥ 18 is correct as far as this finite check goes. ### Inferences
- The group-order bound φ(G) ≤ |G| is false in general (Z/17), but this has no direct bearing on (a): for Z/4 the conjectured value 4 is supported by the n = 3, 4 computations. It does remove the heuristic "φ(G, n) ≤ |G| should hold for structural reasons", so a proof of (a) cannot be a specialisation of a general-G argument.
- The counterexample is compatible with the constancy conjecture (it gives a lower bound uniform in n ≥ 3); (b) remains open for every G other than Z2, Z3, Z2×Z2.
- The counterexample technique (search for small fibres with disjoint supports = indispensable binomials, certify by exhaustive enumeration of a fibre) is directly reusable as a *refutation* tool for (a)/(b): a degree-5 indispensable binomial for Z/4 at some n ≥ 5, or a jump φ(G, n+1) > φ(G, n) for some small G, would be certifiable in the same elementary way.
- Since Z5, Z6, Z7 have φ(G, 3) = 4, 6, 6 (S–S table) but φ(G) is unknown, cheap targets for testing (b) by machine are φ(Z5, 4) (reported = 4 by DB–M if their index means 4 leaves), φ(Z6, 4), φ(Z7, 4).

## Key question 3 — Methods survey (key theorem + applicability verdict for each)

### Takeaway
None of the general stabilisation machineries applies off the shelf: toric fibre products control internal edges but not the valence n of the claw vertex; equivariant Noetherianity (Hillar–Sullivant, DEKL) requires finitely many Sym-orbits of variables, which fails for the full claw-tree family (it holds only for the bounded-support subfamily) and is in any case non-effective; the independent set theorem grows state counts, not the number of leaves. The realistic toolkit is the M–V table combinatorics made effective, plus fixed-n computation (4ti2 up to 256 variables on very large machines, fibre-by-fibre/symmetry-reduced methods beyond), with regularity bounds from normality to cap degrees, and Lean-checkable fibre-connectivity certificates.

### Cited Findings

**3.1 Toric fibre products (TFP).**
- Sullivant, "Toric fiber products", Cor. 2.10: if A is linearly independent and F, G are homogeneous generating sets of I, J, then Lift(F) ∪ Lift(G) ∪ Quad_B generates I ×_A J; Thm 2.9: same with Gröbner bases; Cor. 2.11: squarefree initial ideals are preserved — [arXiv:math/0602052](https://arxiv.org/abs/math/0602052)
- Sullivant Thm 3.10: for a tree T with interior edge e, I_{G,T} = I_{G,T_e^+} ×_A I_{G,T_e^-} with A linearly independent; Cor. 3.11: generators for trivalent T come from those of K_{1,3} — [arXiv:math/0602052, §3.4](https://arxiv.org/abs/math/0602052)
- Michałek 2013 Prop. 4.6 (via [SS05, Thm 26], [Sul07, Cor 2.11]): φ(G, T) ≤ max(φ(G, T_1), φ(G, T_2)) when T is obtained by joining T_1, T_2 at leaves — [arXiv:1207.0930, Prop. 4.6](https://arxiv.org/abs/1207.0930)
- Rauh–Sullivant, "Lifting Markov bases and higher codimension toric fiber products": Thm 30 (codimension-zero case: Lifts(M) ∪ Lifts(M′) ∪ Quads is a Markov basis); Thm 52: if a "PFI Markov basis" of all intersected projected fibres is finite then the Markov degree of all toric fibre powers ×_A^r B is bounded by a constant C, and "a numerical value for the constant C can be computed explicitly"; Cor. 53: if N B^φ is normal then sup_r mardeg(×_A^r B) is finite; Cor. 55/Thm 57: bounded Markov degree for binary K_{2,N}-type hierarchical models — [arXiv:1404.6392](https://arxiv.org/abs/1404.6392)
- Engström–Kahle–Sullivant, "Multigraded commutative algebra of graph decompositions" (higher-codimension TFPs; "compatible projection property", cited as [7] in Rauh–Sullivant Thm 4.2/4.9) — [arXiv:1102.2601](https://arxiv.org/abs/1102.2601) (not read beyond title; cited through Rauh–Sullivant)
- Hollering–Johnson–Portakal–Solus (2023): "quasi-independence gluing", a generalisation of TFP allowing iterative Gröbner basis lifting under combinatorial homogeneity conditions (abstract only) — [doi:10.2140/astat.2023.14.109](https://doi.org/10.2140/astat.2023.14.109)
- Verdict: codimension-0 TFP reduces arbitrary trees to claw trees and gives the *wrong direction* for our problem: K_{1,n+1} is not a TFP of smaller claw trees; rather the TFP K_{1,n} * K_{1,3} is the tree T with one internal edge, and X(K_{1,n+1}) ⊂ X(T) (Michałek 2013 §9; this containment is the content of Conj. 9.2 = DB–M Conj. 3.6, which would give constancy). TFP therefore yields the invariants of X(T) of degree ≤ max(φ(G,n), φ(G,3)) vanishing on K_{1,n+1}, but not that they generate — [arXiv:1207.0930, §9](https://arxiv.org/abs/1207.0930); [arXiv:1011.3236, Prop. 3.9](https://arxiv.org/abs/1011.3236)

**3.2 Noetherianity / finiteness up to symmetry.**
- Hillar–Sullivant, "Finite Gröbner bases in infinite dimensional polynomial rings and applications": Thm 1.1 — K[X_{[r]×P}] is Noetherian as a module over K[X_{[r]×P}] * S_P (variables x_{i,j}, i ∈ [r] bounded, j ∈ P unbounded); Thm 2.19 chain stabilisation for P-invariant chains — [arXiv:0908.1777](https://arxiv.org/abs/0908.1777)
- Draisma–Eggermont–Krone–Leykin, "Noetherianity for infinite-dimensional toric varieties", Main Theorem 1.1: if Sym(N) has only finitely many orbits on Y and φ: R[Y] → R[Z] (Z = {z_{ij}: i ∈ [k], j ∈ N}) is Sym(N)-equivariant sending each y to a monomial, then ker φ is generated by finitely many Inc(N)-orbits of binomials and im φ is Inc(N)-Noetherian. Consequence (2): if P_n ⊆ Z^m × Z^{k×n} with Sym(n)P_{n0} = P_n for n ≥ n0, then there is n1 such that Sym(n)M_{n1} is a Markov basis of P_n for all n ≥ n1. The paper stresses R[Y] itself is typically not Sym(N)-Noetherian. Effectiveness: the abstract says the first factor of the map has "an explicit degree bound" (Yamaguchi–Ogawa–Takemura) "while for the second part the finiteness follows from the Noetherianity of the matching monoid ring"; §5 gives a Buchberger-type procedure but states "we do not know whether a finite Inc(N)-Gröbner basis ... exists" — [arXiv:1306.0828](https://arxiv.org/abs/1306.0828)
- Kahle–Krone–Leykin, "Equivariant lattice generators and Markov bases": treats only maps given by a single monomial; Thm 2.5/Cor. 2.6 give explicit equivariant lattice generators of width k + 2; explicit Markov bases only for width two; notes the DEKL setting is "the most general setting for which ker(π) is known to be finitely generated up to symmetry" — [arXiv:1401.0397](https://arxiv.org/abs/1401.0397)
- Hillar–Martín del Campo, "Finiteness theorems and algorithms for permutation invariant chains of Laurent lattice ideals": Thm 1.3 — every invariant chain of *Laurent* lattice ideals stabilises; Thm 1.4/1.7 — explicit N = 2·deg(f) and an effective algorithm for single-monomial chains; Problem 1.9 "Does every invariant chain of lattice ideals (resp. toric ideals) stabilize?" is posed as open — [arXiv:1110.0785](https://arxiv.org/abs/1110.0785)
- Draisma–Eggermont, "Finiteness results for abelian tree models": for equivariant models with abelian symmetry group, the Zariski closures are defined by equations of bounded degree independent of the tree (set-theoretic), with a polynomial-time membership test; "a qualitative variant of a quantitative conjecture by Sturmfels and Sullivant" — [arXiv:1207.1282](https://arxiv.org/abs/1207.1282)
- Draisma, "Topological Noetherianity of polynomial functors" (downloaded; statement not extracted in this session) — [arXiv:1705.01419](https://arxiv.org/abs/1705.01419)
- M–V 2017 position their theorem relative to this literature: set-theoretic finiteness for equivariant models is [DK09, DE15]; ideal-theoretic finiteness for equivariant models "is beyond any of the methods described in this paper"; they suggest "trying to find combinatorial analogs of Δ-modules [Snowden; Sam–Snowden]" as an unexplored direction and note that summing two columns (a flow of length n+1 → length n) mimics a flattening — [arXiv:1606.07263, §1 and §4](https://arxiv.org/abs/1606.07263)
- Verdict (my analysis of the hypotheses against the cited statements): put q_g ↦ ∏_j a^{(j)}_{g_j}, set a^{(j)}_0 = 1 to embed K_{1,n} ⊂ K_{1,n+1} by padding with the neutral element; then Z = {a^{(j)}_g} has the DEKL shape (k = |G| − 1 rows, columns indexed by leaves) but Y = finitely supported zero-sum flows has *infinitely many* Sym(N)-orbits (one for each zero-sum multiset of non-neutral elements, of unbounded size), so the DEKL Main Theorem does not apply to the full family. It does apply to the subfamily of flows of support ≤ s for any fixed s (finitely many orbits), in particular s = D(G), which by Michałek 2013 Lemma 7.2 is what governs the ideal after saturation by the neutral variable. Even there the output is existence of n1, not a value.

**3.3 Independent set theorem / hierarchical models.**

- Rauh–Sullivant Thm 57 / Cor. 55: explicit Markov degree bounds for binary hierarchical models of K_{2,N} obtained by TFP lifting — a rare *effective* instance — [arXiv:1404.6392](https://arxiv.org/abs/1404.6392)
- Marín Muñoz identifies the Z_m unit-weight orbifold configuration with the group-based model on a claw tree and, separately, some product cases with binary hierarchical models of cross-polytope boundary complexes; over Z2 with cut configurations of explicit graphs — [arXiv:2609.02630](https://arxiv.org/abs/2609.02630)
- Verdict: the independent set theorem lets the *number of states* of some factors grow with the number of factors m fixed; the claw family has |G| states per leaf fixed and the *number of factors* n growing, so it is outside the framework. ### Inferences
- How a computed Markov basis for fixed (G, n) could be certified: by the fundamental theorem (formalised in atlas-lean as `isMarkovBasis_iff_span_eq_toricIdeal`), "M generates I_{G,n}" ⇔ "M connects every fibre". The infinitely-many-fibres part is what needs a finite argument; two standard options are (i) a Gröbner basis certificate (verify S-pairs reduce to zero — checkable but large), or (ii) a degree cap D from regularity/normality or Sturmfels' bound, then connectivity of the finitely many fibres of degree ≤ D modulo symmetry (Sym(n) × G^{n−1}-translations × Aut(G)), each a finite graph-connectivity fact checkable by `decide`/kernel computation or by an external verified checker. Lower bounds (indispensable binomials) are trivially certifiable by fibre enumeration, as in the Z/17 note. Nothing of this kind has been done for group-based ideals in a proof assistant, as far as this sweep found.
- For (a) one only needs: for each degree d ≥ 5 fibre, connectivity under moves of degree ≤ 4. A reduction in the M–V 2019 style ("any degree-d pair of tables can be moved by degree ≤ 4 moves to share a row") is a statement about bounded-size local configurations for large n and is the natural target for exhaustive/SAT search at small n and for a formal proof.
- The bounded-support subfamily (support ≤ D(G) = 4 for Z4) is the place where DEKL-type finiteness and Michałek's Lemma 7.2 meet; a proof that the degree-≤4 part of the ideal is *saturated* with respect to the neutral variable q_0 for Z4 would convert Michałek's scheme-theoretic bound into the ideal-theoretic statement (a).
- Constancy (b) is equivalent, given boundedness, to DB–M Conj. 3.6 "for n large" only; the full Conj. 3.6/9.2 (scheme-theoretic intersection of X(T, G) over prolongations) is strictly stronger than what TFP provides and is the cleanest structural route to (b).

## Key question 4 — Most promising concrete attack routes

### Takeaway
Five routes, ordered by expected yield per unit effort: (1) settle n = 5 (and attempt n = 6) for Z/4 computationally with certificates; (2) make the Michałek–Ventura column-merging induction effective for Z/4, copying the K3P proof architecture; (3) prove saturation of the degree-≤4 ideal w.r.t. the neutral variable, upgrading Michałek's scheme-theoretic bound; (4) attack constancy via DB–M Conj. 3.6 / a direct "merge two columns" lemma for all n ≥ 3; (5) search for counterexamples to (a)/(b) by indispensable-binomial search, Pochuev style.

### Cited Findings
- Baseline facts each route starts from: φ(Z4, 3) = φ(Z4, 4) = 4 (S–S 2005 table) — [arXiv:q-bio/0402015](https://arxiv.org/abs/q-bio/0402015); φ(G, n) ≤ φ(G, n − 1) for n > N, N unspecified (M–V 2017 Thm 3.12) — [arXiv:1606.07263](https://arxiv.org/abs/1606.07263); the K3P proof handled n ≤ 5 by machine, n = 6 by regularity + machine, n ≥ 7 by hand — [arXiv:1704.02584](https://arxiv.org/abs/1704.02584); scheme-theoretic bound via supports ≤ D(G) — [arXiv:1207.0930, Lemma 7.2](https://arxiv.org/abs/1207.0930); Conj. 3.6 ⇔ boundedness for large n — [arXiv:1011.3236, Prop. 3.9](https://arxiv.org/abs/1011.3236); general conjecture φ(G) ≤ |G| is false for Z/17 — [GitHub README](https://github.com/Grisha-Pochuev/phylogenetic-complexity-z17-counterexample)

### Inferences
**Route 1 — Fixed-n computation for Z/4 at n = 5, then n = 6 (targets (a) and, via monotonicity, the first open instances of (b)).**
- First step: compute the Markov basis of the 20×256 configuration (Z4, K_{1,5}) with 4ti2 on a ≥ 1 TB machine (the K3P analogue of identical size succeeded), or avoid the global Gröbner computation: enumerate fibres of degree d = 5, 6, ... up to a regularity cap modulo the symmetry group and test connectivity under degree-≤4 moves (allMarkovBases-style fibre graphs; MultigradedImplicitization for the list of generators in degrees ≤ 4).
- Main risk: memory/time (K3P at n = 5 needed 1 TB; n = 6 was infeasible by pure computation), and the absence of a proved degree cap for Z4 (normality of P_{Z4,n} for n ≥ 4 is not in the literature I read), without which fibre-by-fibre checking cannot terminate with a proof.
- Value even if n = 6 fails: n = 5 is new data, is a base case for Route 2, and a degree-5 generator would refute (a) and (b) at once.

**Route 2 — Effective Michałek–Ventura induction for Z/4 (target (a) for all n).**
- First step: redo M–V 2017 Lemmas 3.10–3.11 for G = Z4 with explicit constants, or better, transplant the M–V 2019 scheme: for a degree-d ≥ 5 pair of tables with n ≥ n0 columns, reduce the Hamming distance between two rows to 0 using moves of degree ≤ 4. Use computer search at n = 5, 6, 7 to discover which cubic/quartic moves are needed (K3P needed specific cubic moves and "counting functions"), and Davenport-constant arguments (D(Z4) = 4) to bound supports.
- Main risk: the case analysis for K3P already ran to dozens of pages and exploited that every element of Z2×Z2 is an involution; Z4 has an element of order 4 and non-symmetric flows (g ≠ −g), so the number of cases may explode; the threshold n0 may be too large for the base cases to be computable (Route 1 limits base cases to n ≤ 5 or 6).

**Route 3 — Saturation route (target (a), possibly (b) for general G in a weak form).**
- First step: let J_n ⊂ I_{Z4,n} be the ideal generated in degree ≤ 4. Michałek's Lemma 7.2 gives q_0^m · B ∈ (quadrics + small-support relations) for each binomial B. Prove (or test by computer for n = 4, 5) that J_n : q_0 = J_n, i.e. q_0 (equivalently every variable, by the G^{n−1}-translation symmetry) is a non-zero-divisor mod J_n. For n = 3, 4 this is a finite Macaulay2 check and tells immediately whether the route is viable.
- Main risk: Lemma 7.2 controls supports, not degrees; one still needs that relations among support-≤4 flows of Z4 are generated in degree ≤ 4 uniformly in n — this is where a DEKL-type finiteness (bounded-support subfamily has finitely many Sym-orbits) is available but non-effective. Non-zero-divisor statements for non-prime J_n are typically as hard as primality of J_n.

**Route 4 — Constancy via column merging / DB–M Conjecture 3.6 (target (b)).**
- First step: isolate the exact statement needed: for every n ≥ 3 and every compatible pair of d×(n+1) tables, quadratic (or degree ≤ φ(G, n)) moves can make two columns agree row-by-row in both tables; then the M–V 2017 Theorem 3.12 argument gives φ(G, n+1) ≤ φ(G, n) verbatim. Test this "two columns can be aligned" statement exhaustively for Z4 (n+1 = 4, 5) and Z5 (n+1 = 4) in small degrees; in parallel compute φ(Z5, 4), φ(Z6, 4), φ(Z7, 4) to test (b) numerically beyond the S–S table (only φ(Z5, 4) = 4 appears to be recorded).
- Main risk: the alignment lemma may simply be false for small n (M–V need n ≫ |G| to find frequent elements), in which case constancy, if true, needs a different mechanism (Conj. 9.2's scheme-theoretic intersection, for which TFP gives only one inclusion); and after Z/17 there is less reason to trust conjectures extrapolated from small tables.

**Route 5 — Refutation search (targets both).**
- First step: adapt the Z/17 technique: for Z4 with n = 5, 6 (and for (b): any small G with n = 4 vs n = 3) search for fibres of degree 5–8 that are disconnected under degree-≤4 moves; simplest signature is a two-element fibre with disjoint supports (indispensable binomial), found by integer programming over row-type multiplicities with a nullity-1 incidence system, exactly the certificate format I re-verified for Z/17.
- Main risk: none mathematically (a negative result is uninformative unless exhaustive); the search space of column-multiset data grows quickly, and disconnected fibres need not be two-element, so a failure to find indispensable binomials does not support (a).
